# Ejercicio: tarjeta de una rana con Flexbox

Recibirás el archivo `index.html` y la imagen `rana.png`, pero no una hoja de estilos. Crea un archivo llamado `styles.css`. Verifica que queda correctamente enlazado.

Aqui tienes la página que debe resultar

https://ejercicioflex-omega.vercel.app/


El objetivo es practicar las propiedades básicas de **Flexbox** creando una cabecera y una tarjeta de producto. Dos de los productos mas habituales que vamos a crear con FLEX.

## 1. Cabecera

Da estilo a la etiqueta `header` para que tenga un fondo rosa, espacio interior y se comporte como un contenedor Flexbox.

- Coloca el logo a la izquierda y alinea su elemento H1 verticalmente en el centro. Recuerda la propiedad que acabamos de ver de flex grow para que H1 ocupe el espacio sobrante en el header. 
- El logo debe ser la imagen de la rana, tener un ancho aproximado de `4rem` y forma circular.



## 2. Tarjeta

Usa la etiqueta `article` como tarjeta.

La tarjeta está centrada ¿que contenedor centra la tarjeta?

Todos los elementos de la tarjeta están centrados. 

- La tarjeta debe medir aproximadamente `20rem` de ancho, tener relleno, borde rosa y esquinas redondeadas.
- Centra el texto de la tarjeta.
- La imagen de la rana que está dentro de la tarjeta debe medir aproximadamente `15rem` de ancho.

### Recordatorio: selector 

Cuando le des estilo a la imagen de la tarjeta usa los selectores que vimos de selectores de descendientes. Si no recuerdas como es este selector usa una clase si te es más fácil. 

## 3. Botón

Haz que el botón `COMPRAR` ocupe todo el ancho de la tarjeta.

- Añade relleno para que sea grande y fácil de pulsar.
- Elimina su borde por defecto.
- Usa esquinas redondeadas, fondo rosa, texto blanco, letra algo más grande y negrita.

## 4. Responsividad

Revisa que el index sea responsivo. Recuerda la propiedad min-width. Le ponemos un tamaño a la tarjeta pero si no tiene espacio suficiente se puede hacer mas pequeña.
